### 程式二 — `rssi/get_exponent.py`

路徑損耗參數 (n, A) 的互動式量測工具，**SSH 登入後手動執行**。

#### 功能摘要

| 功能                  | 說明                                                                                               |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| **BLE 衝突處理**        | 啟動時自動偵測程式一 (`ble-beacon-scanner`) 是否在執行，若是則暫停它，結束後自動重啟                                           |
| **Step 1: 校正 (1m)** | 在 1 公尺處取樣 10 次 RSSI → Kalman 濾波 → 得到參考功率 **A**                                                   |
| **Step 2: 量測其他距離**  | 預設距離 `[2,3,4,5,6,7,8,9,10]` 公尺自動輪流測量（按 Enter 跳下一點），也可手動輸入任意距離。每次取樣 10 次 → Kalman 濾波 → 公式計算 **n** |
| **中斷安全**            | Ctrl+C 時也確保重啟程式一，不會遺留 BLE 適配器被佔用                                                                 |
| **結果儲存**            | 以覆寫方式輸出 `result.txt`，含 A 值與各距離的 RSSI、n 值                                                         |
#### 路徑損耗指數量測（事前準備）

先使用 `rssi/get_exponent.py`（在樹莓派上執行）來量測環境的：

1. **Reference Power (A)**：1 公尺處的 RSSI 參考值
2. **Path Loss Exponent (n)**：環境的損耗指數

取得後填入 `src/environment.py` 的 `RECEIVER_X_TX_POWER` 和 `PATH_LOSS_EXPONENT`。
