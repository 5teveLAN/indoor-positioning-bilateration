## I. 網路設定

#### 目標
設定**雙網路備援**：
1. **首要網路 (Primary)**：教室分享器 Wi-Fi
2. **備用網路 (Failover)**：手機熱點

#### 實作方式

**使用 NetworkManager**
```bash
# 設定主要網路
nmcli connection add type wifi con-name "802.1x_MCU" ifname wlan0 ssid "802.1x_MCU" \
  -- wifi-sec.key-mgmt wpa-eap \
    802-1x.eap peap \
    802-1x.phase2-auth mschapv2 \
    802-1x.identity "12363033" \
    802-1x.password "你的密碼" \
    connection.autoconnect-priority 10
```

```bash
# 查看目前所有連線的優先權
nmcli -f NAME,UUID,AUTOCONNECT-PRIORITY connection show
```
> **注意**：優先順序高的網路斷線時，系統會自動切換到優先順序低的網路。
