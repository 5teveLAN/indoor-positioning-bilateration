### 5.1 設定

在程式中設定 `USE_TEST_MODE = True` 即可離線測試，不需連後端。

| 參數      | 值               |
| ------- | --------------- |
| XOR Key | `TEST_KEY_2024` |


### 5.3 空中的實際封包（Hex 範例）

以學號 `11012345`、OTP `A1B2C3`、XOR Key `TEST_KEY_2024` 為例：

```
原始明文:    11012345|A1B2C3
原始 Hex:   31313031323334357c413142324333
XOR Key:    544553545f4b45595f32303234
加密後 Hex: 656C7D7576776A687B2C25727E1C0C15
```

> 樹莓派收到的是 **加密後的 15 bytes**，需要 XOR 解密才能得到明文。
